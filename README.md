# Зелені стежки Карпат

Навчальний адаптивний лендинг про відповідальне планування мандрівок Карпатами. У ньому є картки трьох демонстраційних маршрутів і фільтр складності, адаптивне меню, локальне відео, вбудовані YouTube і Google Maps, погодний інформер Open-Meteo. Числові параметри маршрутів є навчальними прикладами.

## Структура

- `index.html` — головна сторінка.
- `css/style.css` — стилі.
- `js/main.js` — меню, фільтр і погодний інформер.
- `assets/` — зображення, іконки та відео.
- `.nojekyll` — налаштування GitHub Pages для прямої публікації статичних файлів.
- `netlify.toml` — публікація кореня репозиторію на Netlify без команди збірки.

## Локальний перегляд

Із цієї папки виконайте `python -m http.server 8000`, потім відкрийте `http://localhost:8000/`. Для роботи погодного інформера, шрифтів, Tailwind CDN, YouTube і карти потрібен доступ до зовнішніх сервісів.

## Публікація

GitHub Pages: репозиторій → **Settings → Pages → Deploy from a branch → main / (root)**. Netlify: **Add new site → Import an existing project → GitHub**, оберіть репозиторій; publish directory — `.`; build command — порожня. Докладні кроки та поля для фактичних URL є у `../Instructions/MANUAL_STEPS.md`.

## Походження

Базові дев’ять файлів скопійовано без змін із `Lab_07/site`. Файли попередніх лабораторних робіт залишено на місці. Цей репозиторій використовує локальну технічну адресу автора `lab08@local.invalid`; перед публікацією слід встановити власні `user.name` та `user.email` у Git.
