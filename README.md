# Зелені стежки Карпат — лабораторна робота №9

Адаптивний навчальний лендинг про планування мандрівок Карпатами. Версія ЛР №9 розширює сайт ЛР №8 формою зворотного зв’язку; попередні секції, стилі, JavaScript-меню, фільтр маршрутів і медіа збережено.

## Форма

Форма в `index.html#contact` містить ім’я, email, телефон, повідомлення, обов’язкову згоду та кнопку надсилання. `js/validation.js` перевіряє поля під час `input`/`change`, `blur` і `submit`, показує помилки під полями, оновлює `aria-invalid`, переводить валідні поля в зелений стан та фокусує перше помилкове поле.

Правила: ім’я 2–80 символів (літери, пробіли, дефіс або апостроф), email навчального синтаксичного формату до 254 символів, телефон строго `+380` і дев’ять цифр без пробілів, повідомлення 10–2000 символів, згода обов’язкова. Успішна перевірка очищає форму й відкриває доступний стилізований HTML `<dialog>` із кнопкою закриття, Escape та поверненням фокуса. Без підтримки `<dialog>` показується текстовий стан.

**Дані не надсилаються:** немає бекенду, `fetch` або сховища для форми. Кнопка спочатку вимкнена й активується лише після завантаження JavaScript, щоб без сценарію не надсилати дані як GET-запит. Сторінка `privacy.html` пояснює межі демонстрації. Для тестів використовуйте вигадані дані.

## Структура

- `index.html`, `privacy.html` — сторінки.
- `css/style.css` — попередній дизайн і стилі форми.
- `js/main.js` — попередні взаємодії сайту.
- `js/validation.js` — правила та інтерфейс валідації.
- `assets/` — зображення, іконки й відео з попередніх лабораторних.

## Локальний перегляд і публікація

У цій папці: `python -m http.server 8000`, потім `http://localhost:8000/`. Зовнішні Tailwind CDN, Google Fonts, YouTube, Google Maps та Open-Meteo потребують мережі. У Vercel імпортуйте **цей** Git-репозиторій із кореневим `index.html`, Framework Preset **Other**, Root Directory `./`, без команди збірки. Публічний URL з’явиться тільки після вашого входу та деплою.
